Пользователь выбирает закладку "Граф" в карточке сущности. Переход на окно  графа объектов с изображением выбранной сущности и связанных с ней сущностей. Каждый объект графа должен содержать наименование контейнера (кроме объекта модели данных), наименование объекта, тип объекта и список его атрибутов (по умолчанию скрыты).  Для объектов типов представления, таблицы, json-файл, входящий вектор  это список наименований атрибутов (столбцов), Для объекта моделей вместо списка столбцов отображается наименование входящего вектора. Для объектов с типами представления, таблицы наименование контейнера это наименование БД, для векторов и JSON файла контейнер - наименование модели, у объектов модели наименование контейнера не указывается. По умолчанию атрибуты скрыты. Узел модели данных должен отрисовываться для каждой уникальной сущности с типом input_vector в массиве entities JSON основы, наименование модели вектора находится в поле entities.namespace, описание модели в поле entities.container_description, дата и время создания записи модели в БД в поле entities.container_change. Имя входящего вектора модели - entities.name в объекте вектора.2.  Для просмотра списков атрибутов отдельного объекта пользователь кликает в объекте на управляющий элемент-переключатель режимов просмотра (с атрибутами/без атрибутов) и на объекте раскрывается список атрибутов. Если атрибутов больше 10-ти, то список отображается в сокращенном виде и над ним строка поиска атрибута. Повторный клик на управляющий элемент скрывает атрибуты.3. Для отображения/скрытия атрибутов на всех объектах графа пользователь  кликает ПКМ на свободном пространстве окна графа, отображается всплывающее меню с разделами "Отобразить атрибуты", "Скрыть атрибуты". Если пользователь выбирает раздел "Отобразить атрибуты" для всех связанных объектов  отображаются  их атрибуты. Если пользователь выбирает раздел "Скрыть атрибуты" для всех связанных объектов  скрываются их атрибуты. 4. Пользователь может воспользоваться строкой поиска для перехода в списке атрибутов объекта графа на нужный атрибут. Если атрибут найден он отображается в списке (список смещается к искомому атрибуту).5. Пользователь выбирает в атрибут объекта чтобы отследить его связи, в окне графа подсвечивается рамкой/заливкой атрибут,  выделяется цветом связь этого атрибута и связанный с ним атрибут второго объекта ( рамкой/заливкой).  При выделении одного атрибута для просмотра его связей все остальные связи атрибутов на схеме должны быть скрыты.    6. Пользователь кликает в линию связи атрибутов, открывается окно с информацией о связи: описание связи объектов, наименование объекта источника, наименование атрибута источника, его тип, описание атрибута источника, наименование целевого объекта, наименование атрибута цели, его тип, описание атрибута цели, наименование процесса. Если пользователь кликает в другую связь атрибутов, информация в окне "Информация о связи" обновляется на актуальную. Для функциональной связи в окне "Информация о связи" отображается SQL функции в которых используется атрибут источника (LIKE, WHERE, ORDER BY).7. Для просмотра детальной информации о связи между объектами пользователь дважды кликает в линию связи, открывается окно с маппингом атрибутов связи (Подробнее см. )8.  Для просмотра в табличном виде детализации по всем атрибутам и связям любого из отображаемых  объектов графа пользователь должен выбрать нужный объект и перейти на карточку этого объекта в закладке "Детали". Отображается карточка выбранного объекта (см. )Для объекта модели отображается детализация модели с сокращенным набором данных см.
