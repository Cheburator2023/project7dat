Информация

В раздел Target отчёта S2T требуется поместить данные одной выбранной пользователем витрины.

В раздел Source отчёта S2T требуется записать данные всех источников выбранной пользователем витрины за исключением временных таблиц.

Алгоритм формирования отчёта

1. По шаблону отчёта S2T требуется создать новый незаполненный данными excell файл.

2. На листе Mapping требуется заполнить раздел Source данными атрибутов всех нетемповых источников из массива mappings для выбранной пользователем витрины в привязке к атрибутам витрины записанных в разделе разделе Target.

2. Темповой таблицей источника считается любая таблица в имени которой присутствуют лексемы "temp_" или "_temp". Разделы Source и Target листа отчёта Mapping заполняются согласно маппингу в разделе "Соответствие полей JSON полям отчёта S2T (Source To Target)" (см. раздел выше)
