# Artillery Load Testing для Data Lineage API

Этот каталог содержит конфигурации Artillery для нагрузочного тестирования API Data Lineage с автоматической генерацией тестов из OpenAPI спецификации.

## Установка

```bash
cd artillery
npm install
```

## Быстрый старт

### Автоматический запуск всех тестов
```bash
./run-all-tests.sh
```

### Из корневой директории проекта
```bash
npm run test:load:smoke      # Дымовое тестирование
npm run test:load:basic      # Базовое нагрузочное тестирование
npm run test:load:stress     # Стресс-тестирование
npm run test:load:endurance  # Тест на выносливость
npm run test:load:all        # Все тесты подряд
```

## Автоматическая генерация тестов

### Генерация из OpenAPI спецификации
```bash
npm run generate            # Генерация тестов из OpenAPI
npm run test:auto           # Запуск автоматически сгенерированных тестов
npm run generate:test       # Генерация + запуск
```

Скрипт автоматически:
- Получает OpenAPI спецификацию с `http://localhost:3000/api/docs-json`
- Анализирует все эндпоинты и их параметры
- Генерирует соответствующие сценарии тестирования
- Создает динамические данные для запросов
- Сохраняет конфигурацию в `auto-generated-test.yml`

## Типы тестов

### 1. Дымовое тестирование (Smoke Test)
Быстрая проверка всех эндпоинтов с минимальной нагрузкой.
- **Нагрузка:** 5 пользователей, 30 секунд
- **Цель:** Проверка доступности всех эндпоинтов

```bash
npm run test:smoke
```

### 2. Автоматически сгенерированные тесты
Тесты, созданные автоматически из OpenAPI спецификации.
- **Нагрузка:** 10 пользователей, 2 минуты
- **Цель:** Полное покрытие всех эндпоинтов API

```bash
npm run test:auto
```

### 3. Базовое нагрузочное тестирование
Стандартное нагрузочное тестирование с умеренной нагрузкой.
- **Фазы:** Разогрев → Основная нагрузка → Остывание
- **Пиковая нагрузка:** 20 пользователей

```bash
npm run test:basic
```

### 4. Стресс-тестирование
Интенсивное тестирование с высокой нагрузкой для проверки пределов системы.
- **Пиковая нагрузка:** 100 пользователей
- **Цель:** Определение точки отказа системы

```bash
npm run test:stress
```

### 5. Тест на выносливость
Длительное тестирование для проверки стабильности системы.
- **Длительность:** 30+ минут
- **Цель:** Проверка утечек памяти и деградации производительности

```bash
npm run test:endurance
```

## Генерация отчетов

### Объединенный HTML отчет
Создание единого, красиво оформленного отчета для всех тестов:

```bash
npm run test:all:with-report    # Запуск всех тестов + генерация объединенного отчета
npm run report:combined         # Только генерация объединенного отчета
```

Объединенный отчет включает:
- 📊 **Общую сводку** с ключевыми метриками
- 📈 **Интерактивные графики** времени отклика и количества запросов
- 🔍 **Детальные секции** для каждого типа теста
- 📋 **Таблицы латентности** с процентилями
- 🎯 **HTTP коды ответов** и их распределение
- 📊 **Счетчики сценариев** и их выполнение

### Автоматические отчеты
Скрипт `run-all-tests.sh` автоматически создает:
- JSON отчеты для каждого теста
- HTML отчеты с графиками и метриками
- Сводный отчет в формате Markdown
- **Объединенный HTML отчет** со всеми результатами

### Ручная генерация отчетов
```bash
npm run report              # Генерация отчетов из последних результатов
artillery report results.json --output report.html
```

## Тестируемые эндпоинты

### Базовые эндпоинты
- `GET /` - Приветственное сообщение
- `GET /health` - Проверка состояния сервера

### JSON данные
- `POST /api/json-data/create` - Создание нового JSON документа
- `GET /api/json-data/list` - Получение списка документов
- `GET /api/json-data/current` - Получение последнего документа
- `GET /api/json-data/{id}` - Получение документа по ID
- `PUT /api/json-data/update/{id}` - Обновление документа
- `DELETE /api/json-data/delete/{id}` - Удаление документа
- `POST /api/json-data/set-current/{id}` - Установка текущего документа

### JSON коммиты
- `POST /api/json-commits/initialize` - Инициализация нового графа
- `POST /api/json-commits/commit` - Создание коммита
- `POST /api/json-commits/commit/{id}` - Обновление с коммитом
- `GET /api/json-commits/commits` - Получение списка коммитов
- `GET /api/json-commits/commits/all` - Получение всех коммитов
- `GET /api/json-commits/commits/search/{id}` - Поиск коммитов

## Конфигурация нагрузки

### Базовый тест
- Разогрев: 60 сек, 5 запросов/сек
- Основная нагрузка: 120 сек, 10 запросов/сек
- Охлаждение: 60 сек, 2 запроса/сек

### Стресс-тест
- Разогрев: 30 сек, 10 запросов/сек
- Высокая нагрузка: 60 сек, 50 запросов/сек
- Пиковая нагрузка: 120 сек, 100 запросов/сек
- Снижение: 60 сек, 20 запросов/сек
- Охлаждение: 30 сек, 5 запросов/сек

### Тест на выносливость
- Разогрев: 5 мин, 5 запросов/сек
- Основной тест: 30 мин, 15 запросов/сек
- Охлаждение: 5 мин, 2 запроса/сек

## Генерация тестовых данных

Тесты используют библиотеку Faker.js для генерации реалистичных тестовых данных:
- Случайные названия документов
- Сложные JSON структуры с сущностями и связями
- Метаданные с временными метками
- Различные типы данных для проверки обработки

## Мониторинг результатов

Artillery автоматически выводит метрики:
- Количество запросов в секунду (RPS)
- Время отклика (латентность)
- Процент успешных запросов
- Ошибки и их типы
- Использование ресурсов

## Требования

- Сервер должен быть запущен на `http://localhost:3000`
- API должно быть доступно по указанным эндпоинтам
- База данных должна быть настроена и доступна
