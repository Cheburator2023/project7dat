Алгоритм формирования JSON отчёта

Цель Для одной выбранной пользователем витрины требуется сформировать JSON с одним массивом объектов связей витрины с источниками. Массив должен содержать объекты двух типов, сначала объекты связей витрины и её источников на уровне таблиц, затем объекты связей столбцов витрины и столбцов столбцов источников.

  1. В JSON DL сервис должен по идентификатору выбранной пользователем витрины (entities .entity_id) найти её объект в массиве entities, затем найти объект витрины в массиве mappings по системному идентификатору сущности в РБД (при условии entities .entity_id = mappings.target_id).
  2. Сервис должен по всем объектам источников из массива связей витрины mappings.deps сформировать согласно маппигу объекты ассоциации на уроне таблиц и добавить их в массив JSON отчёта (исключая темповые таблицы).
  3. Сервис должен по всем объектам источников из массива связей витрины mappings.deps сформировать согласно маппингу объекты ассоциации на уроне столбцов таблиц и добавить их в массив JSON отчёта (исключая темповые таблицы).
  4. Обработан последний объект mappings.deps витрины.
  5. Процесс завершён. Отчёт сформирован.

Маппинг таблиц ( "association": "table")

toObject

Название витрины

entities.namespace + "/" + entities.name

Переход на её объект связей mappings по условию равенства системных идентификаторов сущностей объектов:

mappings.target_id = entities.entity_id

Уникальное имя выбранной пользователем витрины.

Пример: "toObject": "prod_dm_dadm_pvrkkb/ead_md"

"flagTmpSrc"

Флаг временной таблицы для источника

Если строка наименования таблицы источника entities.name содержит в начале лексему "tmp_" или в конце строки "_tmp", тогда таблица считается темповой

"flagTmpSrc": true

Иначе таблица будет не темповая, основная,

"flagTmpSrc": false

mappings.target_id = entities.entity_id

Пример: "flagTmpSrc": false

Имя таблицы источника можно также получить из mappings.deps.entityId. Для этого из строки надо удалить всё до точки (наименование БД), включая саму разделительную точку.

"flagTmpTrg"

Флаг временной таблицы для целевой

Если строка наименования таблицы витрины entities.name содержит в начале лексему "tmp_" или в конце строки "_tmp", тогда таблица считается темповой

"flagTmpSrc": true

Иначе таблица будет не темповая, основная,

"flagTmpSrc": false

Пример: "flagTmpTrg": false,

"fromObject"

entities.namespace + "/" + entities.name

Данные из объектов mappings и entities при условии:

mappings.deps.source_id = entities.entity_id

Пример: "fromObject": "prod_repl_cld_pravoru/arbitrage_casecard",

"association"

Тип связи сущностей, здесь это таблицы источник-цель.

= "table"

Пример: "association": "table",

"toConnection"

Система таблицы витрины

mappings.system_code

Пример: "toConnection": "DAPP",

"fromConnection"

Система таблицы источника

mappings.deps.system_code

Пример: "fromConnection": "",

"srcDescription"

Описание таблицы источника

entities.description

Данные из объектов mappings и entities при условии:

mappings.deps.source_id = entities.entity_id

Пример: "srcDescription": "Информация об участниках дел из сервиса pravo.ru/Детальная информация по арбитражному делу из сервиса pravo.ru"

toObject

Наименование БД витрины, витрины и её столбца.

Данные из объектов mappings и entities при условии:

fromObject

Наименование БД источника, таблицы источника и её столбца.

entities.namespace + "/" + entities.name + "/" + mappings.deps.attrMaps.src

mappings.deps.source_id = entities.entity_id
