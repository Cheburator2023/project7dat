Выгрузка файла отчёта из системы

Цель. Пользователь хочет выгрузить для выбранной в системе витрины файл отчёта в формате S2T или JSON. Система должна сформировать и сохранить файл отчёта в выбранном им формате (S2T или JSON)

Предусловия. Пользователь авторизован в системе и выбрал витрину (таблица или view) для формирования отчёта.

Ограничения. Отчёт формируется только для не темповых сущностей (таблица или view).

1. Пользователь в меню главного окна системы "Экспорт данных" выбирает раздел "Формат S2T" или "Формат JSON".

2. Система выводит диалог для сохранения файла отчёта. По умолчанию файл отчета состоит из наименования выбранной витрины (Схема + "." + Таблица) плюс системные дата и время формирования отчета в формате YYMMDDHHMM . Расширение для отчётов S2T в формате Microsoft Excel должно быть ".xlsx", для отчётов в формате JSON - ".json"

Например:

prod_dm_dadm_pvr.pd_mb_behaviour_online2601231543.xlsx

prod_dm_dadm_pvr.pd_mb_behaviour_online2601231543.json
